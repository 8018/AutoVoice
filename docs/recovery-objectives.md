# 恢复目标与故障场景(2026-09-12)

> 依据用户 2026-09-12 决策 Q5:「首期单实例,允许重启后建立新会话、导航重新搜索。
> **删除"RPO=0、RTO≈12s"的对外承诺,改为按故障场景实测**」,以及约束 3:
> 「本地 SQLite 持久化不能推出 RPO=0」。

## 一、不作出的承诺

以下表述**不得对外使用**(此前文档中出现过,现已作废):

- ~~"RPO = 0"~~——单机本地 SQLite 不能保证磁盘/主机损坏下的零数据损失;
- ~~"RTO ≈ 12s"~~——12s 只是"进程启动到监听"的实测值,不含故障发现、依赖就绪、
  客户端重连与业务恢复;
- ~~"重启后无缝继续"~~——会话与导航候选在内存中,重启即丢失,客户端需重新建立会话
  (服务端明确返回 `reset`,客户端清理待选列表并要求重新搜索)。

## 二、状态分层与丢失边界

| 状态 | 存放 | 进程重启 | 主机重启 | 磁盘损坏 |
| --- | --- | --- | --- | --- |
| 会话上下文(owner/resumeToken) | 内存 | **丢失** | 丢失 | 丢失 |
| 导航候选(TTL 120s) | 内存 | **丢失** | 丢失 | 丢失 |
| Realtime 闲聊会话 | 内存 | 丢失 | 丢失 | 丢失 |
| 动作身份 + 审计 | 独立 SQLite | 保留(需验证刷盘) | 保留 | **可能丢失** |
| 手机动作本地账本 | Android SQLite | 保留 | 保留 | 可能丢失(App 重装即丢) |
| 诊断事件/音频 | SQLite(音频默认不落盘) | 保留 | 保留 | 可能丢失 |

## 三、按场景的预期行为与实测项(待环境验证)

| 场景 | 预期行为 | 数据影响 | 待实测项 |
| --- | --- | --- | --- |
| `systemctl restart autovoice-gateway` | 客户端重连得 `new`/`reset`;导航需重新搜索 | 候选丢失;动作账本保留 | 重启后 `findByActionId` 仍可查;**记录从发起到业务可用的实际耗时**(含依赖就绪与客户端重连) |
| 网关进程崩溃(OOM/kill) | 同重启;在途轮次失败,客户端按 `reset` 清理 | 同上 | 崩溃后是否有残留半写记录;恢复耗时 |
| 主机重启 | 同重启 | 同上 | 服务自启顺序(依赖先就绪);磁盘数据完整性 |
| 磁盘损坏/数据库文件损坏 | 服务拒绝启动或账本不可读 | **可能丢失动作记录** | 损坏检测与明确失败(不得静默当空库) |
| 断网重连(网络切换) | `resumed`(会话有效)→ 保留候选;`reset` → 清理 | 无(内存状态尚在) | 蓝牙/切网下的重连成功率与耗时 |
| 客户端 App 重装 | 本地账本丢失 | 本地幂等记录丢失 | 见下方"残留风险" |

## 四、幂等与恢复的边界(约束 1 的延伸)

**审计保留期 ≠ 幂等记录保留期**:动作身份的支持窗口(默认 24h)独立于审计保留期(90 天);
窗口内的请求即使审计记录已被清理,仍按"已签发"判定,不会当新动作执行。

**超过支持窗口的请求明确拒绝**(服务端下发 `actionExpiresAtMs`,客户端拒绝执行)。

**新会话下重发旧动作的行为**(必须验证,不能仅凭存在 actionId 就认定不会重复执行):

| 情况 | 期望行为 |
| --- | --- |
| 新会话 + 窗口内旧 actionId + 本地账本有记录 | 幂等命中,**不重复执行** |
| 新会话 + 窗口内旧 actionId + 本地账本无记录(如 App 重装) | **当前实现无法识别**:会按新动作执行(见下方残留风险)。客户端首期不查询服务端账本(决策 Q2:不开放该接口) |
| 新会话 + 超出窗口的 actionId | **拒绝执行**(明确原因) |
| 服务端账本不可读 | 拒绝下发新动作身份(D14c 已实现) |

**残留风险(如实记录,当前实现未消除)**:

- **同一窗口内,客户端本地账本不可用(如 App 重装)时,窗口内的旧 actionId 会被当作新动作执行。**
  当前判定顺序为:窗口校验 → 本地账本查记录 → 无记录则 claim 并执行;
  **客户端不查询服务端账本**(Q2 决策首期不开放该接口),因此该情况当前无兜底。
- 触发条件需同时满足:①旧动作消息被重放;②客户端本地账本丢失;③仍在支持窗口内(默认 24h)。
- 已实施缓解:本地账本持久化、支持窗口限制 24h、动作能力首期只开放模拟动作
  (真实车控关闭,D07b 执行入口对真实车控无执行器)。
- **升级路径(真实写工具开放前必须完成)**:要么开放服务端账本查询供客户端对账,
  要么由服务端参与执行准入;两者都需单独评审。**在那之前不得开放真实有副作用工具。**

## 五、验证方式

- 上述"待实测项"需在服务器/真机上执行并记录**实际数值**,不使用估算;
- 恢复目标(SLO)在实测数据出来前不对外承诺;
- 每次发布在 `releases/<sha>/metadata.txt` 记录环境与产物摘要(D13),便于故障追溯。
