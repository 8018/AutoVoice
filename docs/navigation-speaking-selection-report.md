# 候选播报与随时选择修复

用户要求：候选出现后，可以直接说“第一个／第二个”选择；准备播报、正在播报和播报结束后的等待阶段均不需要再次唤醒。播报结束后保留等待时间，不代表此时才开放选择。

## 已定位问题

- Open 通道使用原生 VAD 和软件回声消除，但原来的打断开关依赖另一通道的 VAD 对象，因此始终关闭。改为检查实际通道的回声消除和新鲜播放参考；仍然阻止扬声器回声触发。
- 原来的 10 秒会话计时同样用于正在播报，长候选尚未播完就退出。等待、有效输入、处理、准备和播放分别计时，旧轮回调不能结束新轮。
- 静默准备播报时没有普通语音入口。本批补入准备阶段监听，检测到用户说话后取消待播输出；开始出声后切换为有回声保护的打断监听。
- 噪音触发但未被识别接受的录音不能耗尽唯一打断机会；结束后重新开放检测。

## 真机验收步骤（尚未运行）

1. 查询公共地点，候选出现但还没开始说话时说“第二个”：直接选择当前第二项。
2. 再次查询，播报第一项时说“第二个”：无需再次唤醒，接受选择后停止旧播报并交接对应地点。
3. 不打断，等待超过 10 秒：候选播报应继续；播完后仍可选择。
4. 播报中出现短噪音，然后说“第一个”：噪音不能执行导航，也不能让后续选择失效。
5. 连续两轮查询并选择：旧轮播放完成、失败或开始回调不能关闭新轮，也不能选中旧列表。
