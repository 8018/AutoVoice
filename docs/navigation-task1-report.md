# 导航任务 1 执行反馈

## 实现

- URI 执行器声明可用能力，返回带操作身份的 `NavigationActionResult`。打开请求被系统接受时返回 `ACCEPTED`。候选等待返回 `PENDING`，取消应用内目的地选择返回 `SUCCEEDED`。尝试结束外部导航时提示用户在高德地图内操作。
- 导航确认及取消沿用任务、版本、候选列表和候选项的校验。语音回包复用现有轮次去重，语音与点选共用候选领取。相同确认重放时操作身份一致，迟到结果不播报、不启动地图。
- 端侧使用实际打开结果生成回复。单点交接提示查看导航，多点交接提示查看路线规划，拉起失败提示检查高德地图是否已安装。云端下发的完整音频在已有客户端执行反馈时被替换。
- Qwen Omni 在导航工具验证后直接下发 action，由设备处理地图交接后合成回复。客户端在收到已包含导航意图的完整流时丢弃其中的 PCM。旧服务端若先发音频、流结束才给意图，客户端能在结束时根据执行结果纠正回复，已播放的音频受协议顺序限制。
- 执行统计记录状态、耗时以及 `unsupported`、`invalid_request`、`stale_task`、`map_open_failed` 等失败类别。新增导航执行事件字段省略话术、地址和坐标。
- 常用地址接入同一执行器。可信本机单点 WGS84 使用 `dev=1`，普通服务端意图使用 `dev=0`。缺少坐标转换的多点 GPS 请求在打开地图前拒绝。

## 验证

- 客户端 RED。原实现的新增或更新断言共 6 项失败，涵盖地图交接继续播报云端确认、失败话术、缺少能力及单点和多点话术。取消外部导航、GPS 多点拒绝的边界回归另有 2 项预期失败。
- 客户端 GREEN。运行 `:voice-business:test :app:testOpenDebugUnitTest --offline --configure-on-demand`，导航业务 57 项、Open 客户端 234 项，均无失败或跳过。包含流式 PCM 丢弃、同轮常用地址覆盖、执行失败分类和旧确认重放。
- 语音服务 RED。Qwen 回归中实际返回 `audio`，预期 `action`。实现后 `:speech-qwen-omni:test --offline` 31 项通过，无失败或跳过。
- `git diff --check` 通过。
