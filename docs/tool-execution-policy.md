# 显式工具执行策略

## 范围

FunctionTool 携带本地可信 ToolExecutionTraits（readOnly、parallelSafe、cacheSuccess）。
旧三参数构造默认 UNKNOWN：串行、不缓存。不再使用 search/get/geo 等名称推断能力。
这些声明不从模型输出采纳，也不自动信任外部 MCP 工具注释；由适配代码显式设置。
压缩 schema 时保留声明，每次模型请求的工具快照同步固定执行策略。
重复工具名称保守降为 UNKNOWN，避免权限合并导致放宽执行。

内置 resolve_navigation 已声明为独立只读查询；原始外部 MCP 工具默认保守处理。
其他工具必须经适配器明确声明后才恢复并行/缓存；本次没有修改 Skill 平台数据库或配置 UI。

## 缓存与失败

仅请求内共享可缓存的成功查询，包括同批正在执行的相同读取。异常仍作为错误 tool_result
返回模型，但不作为成功文本缓存；完成失败后移除缓存项，允许模型在轮数和时间预算内再次调用。
同批已等待失败的调用收到同一次失败，不在内部自动重试。
工具如果把业务失败包装成普通成功字符串，必须由其适配器转换成异常；不依靠文本猜测错误。

缓存键递归排序 JSON 对象字段，保留数组顺序、字符串内容和数据类型。
非对象、重复 JSON 字段、尾随内容或非法 JSON 不缓存，但仍交由工具自身校验。
未知/有副作用操作前等待已有读取，并清除之前的读缓存，防止操作后沿用旧状态。

## 不包含的能力

没有自动重试写操作，没有把普通缓存当作操作幂等。相同写调用会独立执行。
真正对接可重试的远端写操作前，需要供应商支持 operationId/幂等键及结果查询。
没有引入依赖图或参数引用协议。模型同批发出的调用参数须已完整、相互独立；
依赖前序工具结果的调用应放在下一轮，或在业务工具内按顺序编排。

## 回归

覆盖显式查询并行、未知工具保守行为、成功复用、失败后再次调用、
字段顺序归一化、途经点数组顺序保留、非法参数不缓存、操作使旧缓存失效、
schema 压缩保留声明和重复名保守处理；兼容上一批执行预算的并行/缓存等待测试。
