# 出发前驾车路线查询

2026-11-13 在开发环境，用公开的北京地点坐标验证现有高德授权。探测只记录接口字段、成功状态和公开样例的路线指标。

| 能力 | 实测 |
| --- | --- |
| 高德 MCP 驾车路线 | `maps_direction_driving` 要求 `origin` 和 `destination` 两个字符串。返回 1 条路线，3215 米、1028 秒。此工具未提供策略或途经点参数，样例未返回过路费。 |
| 高德 Web 路径规划 2.0 | 同一开发授权请求 `/v5/direction/driving`，默认策略返回 3 条路线。依次为 3215 米/1099 秒、3413 米/999 秒、3438 米/1187 秒，样例过路费字段均为 0 元。 |
| 高德 Web 途经点和偏好 | 同一公开样例加 1 个途经点、采用不走高速策略 35，返回 2 条方案。策略是供应方算路输入，结果保留其估算含义。 |
| 高德坐标转换 | `/v3/assistant/coordinate/convert` 的 GPS 坐标请求成功并返回高德坐标。 |

[高德 MCP](https://lbs.amap.com/api/mcp-server/) · [高德 Web 路径规划 2.0](https://lbs.amap.com/api/webservice/guide/api/newroute) · [高德坐标转换](https://lbs.amap.com/api/webservice/guide/api/convert)

## 接入

- 服务端使用已启用的官方高德导航技能中的 Web 服务授权，固定请求高德 Web 服务域名。服务端筛选授权来源并禁用重定向，用户可见错误只给出业务状态。
- 客户端请求带操作 ID、已选目的地、有效起点、按序排列的至多 4 个途经点和规划偏好。GPS 坐标经官方接口转换，转换失败时不调用算路。
- 结果带预览集合 ID、路线 ID、规划时间、来源和实际算路坐标。每条预览的预计米数、秒数和过路费分别可空。缺字段保持未知，服务返回的 0 元仍是有效值。
- “去某地要多久”等语音或文字请求走地点解析，选中候选后进入只读预览。路线偏好随地点候选、多轮换批和多点草稿携带。对明确的路线查询，即使模型漏填预览模式，服务端仍限定为只读查询。模型直接返回导航动作时提示明确地点。旧客户端只收到升级提示，避免误开地图。
- 预览内的路线 ID 不代表活动行程。通过外部高德打开时，由高德 App 重新规划。活动行程的剩余时间、剩余里程、到达时刻和结束仍由地图执行端证据决定。

## 验证范围

- 开发环境已对官方高德接口实测。查询服务和网关的本地回归覆盖 GPS 转换、途经点、偏好、未知费用、选点后只读查询，以及网关会话绑定和错误后重试。
- 端云共享协议包含预览请求、结果和带匹配依据的草稿样例。本地 Android 网关测试验证结果身份与未知值。
- 本报告未包含实际驾驶、目标设备中的高德地图回调或导航闭环证据。
