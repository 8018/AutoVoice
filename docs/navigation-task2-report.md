# 导航任务 2 服务端实施报告

范围为 A01—A06、B01—B09、H01。客户端继续使用既有候选、列表身份和采用确认协议。此次变更涉及服务端导航域、MCP 地点工具、地点结果转换、应用装配和导航提示词。

## 实现与覆盖

| 验收项 | 服务端实现与证据 |
| --- | --- |
| A01、A02 | 地图搜索返回有名称、合法坐标的候选。带门牌的查询检查结果是否包含完整门牌，查不到时请用户确认地址。 |
| A03 | 明确城市和区县进入结构化检索条件。指定城市时使用城市文本搜索，供应方 schema 支持时发送 `citylimit`，丢弃明确标记为其他城市的结果。区县依据供应方区县字段或名称、地址验证。 |
| A04 | 明确 T2 等航站楼或入口时匹配该部件。机场中心、其他航站楼和未请求的附属店铺被排除。T2 与 2 号航站楼可互相匹配。 |
| A05、A06 | 车辆附近使用有效车辆坐标并校验结果范围。指定参考点时先消歧并解析参考点，再以参考点为中心进行周边搜索。坐标缺失时仅对唯一可验证的参考点补坐标。参考点歧义时询问更具体的名称或地址。无有效定位、明确城市或参考点时，请用户补充城市。 |
| B01—B03 | 单列表最多三项。播报名次与下发列表一致，包含名称和已知地址。序号只匹配当前列表，名称或地址须唯一匹配。 |
| B04、B05 | 服务端从已采用列表恢复原查询条件，异步重查用户补充的城市或区县，或在换批时过滤此前展示过的地点。无更多结果时明确提示。新结果采用后旧列表失效，取消后迟到结果无法生成替换动作。 |
| B06—B09 | 识别显式改去其他地点并交给既有的新地点解析流程。取消只针对待选搜索。否定序号返回澄清。过期或已替换列表的序号要求重新搜索。 |
| H01 | 通过附近搜索返回合法充电地点候选，播报充电桩空闲状态未知。 |
| 任务 3 接线 | Classic 和 Hybrid 的共用入口拦截与客户端匹配的精确常用地址口令，保留上层的 ASR 文本以供客户端处理。旧端收到明确的设备能力提示。 |

## 验证

在 `AutoVoiceServer` 中使用 Gradle 8.9 和 Java 21。依赖缓存建立后最终以离线方式运行。

```sh
gradle --offline --no-daemon --continue \
  :navigation-domain:test :skill-mcp:test :agent-loop:test :contracts:test :app:compileJava
```

结果为 `BUILD SUCCESSFUL`。JUnit XML 共计 191 项，导航域 35、MCP 83、代理循环 29、契约 44，均无失败、错误或跳过。应用装配编译通过。Gradle 提示有待兼容 Gradle 9 的弃用项。`git diff --check` 通过。

测试先复现了否定序号误执行、地区描述未命中、否定后改目的地误取消、城市和区县条件缺失、参考点中心错误、T2 接受机场中心、缺定位继续搜索、换批重复、充电状态未提示、候选耗尽反馈缺失、迟到换批和常用地址绕入模型等失败。最终回归还覆盖了非法途经点、同名参考点、参考点坐标补齐、异地结果过滤以及航站楼别名与附属店铺。

## 边界和待验收

- 无后缀城市的自然文本识别覆盖显式城市参数、直辖市、带“市”后缀和一组常见“城市的地点”表达。其余城市表达依赖模型按工具契约提取，需用真实语音样本验收。
- 换批从单次供应方召回窗口内选取新结果。通用搜索请求最多 20 条，车站为 25 条。供应方接口未在本次接入独立翻页，耗尽提示对应当前可用召回。无替换列表时，原列表保留至显式关闭或过期。
- 多点输入会完整校验，非法站点阻止整条路线执行。逐站消歧和整条草稿确认属于任务 4，任务 2 沿用既有多点预览入口。
- 地点检索测试以可控的 MCP 回包验证请求和结果，实际地图服务、安卓选择回归、两轮音频到地图交接、定位和候选延迟仍需整体验收。此次未部署。

## 根审核补修

审核发现全文本中文数字归一化会损坏三亚、三河市和二七区等地区名。现仅在序号及候选比较中保留数字等价，地区检索参数保留原字。新增回归先失败后通过；补修后导航域36项测试通过，原合计191项为补修前记录。
