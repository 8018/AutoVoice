# 地点条件和补能规划验收记录

## 地点查询

| 条目 | 当前行为 | 数据边界 |
|---|---|---|
| A07 具体别名 | 以用户提供的别名查候选。仅当高德地点详情的登记别名与请求一致时展示可选候选，播报别名依据，由用户选择。 | “有摩天轮”等描述性特征缺少结构化来源时请求补充地点名称，或请用户明确可放宽的条件。 |
| A08 品牌和分类 | 品牌依据地图地点名称里的文本，分类依据高德返回的分类层级。服务端先核验各站全部已支持的条件，再截取最多三个候选。 | 名称匹配只说明地图名称含品牌文字。地点登记资料更新时间未知，返回的 `retrievedAt` 表示本次读取时间。 |
| A08 营业和经营属性 | 无法核验当前营业或描述性特征时，返回文字澄清，无可选地点或行程草稿。 | 公开 POI 文档提供营业时段、别名等可选资料。开发环境详情返回 `open_time`，本次缺少可核验的实时营业状态和时效信息。 |

开发环境只读发现中，地点文本查询样本返回 `name`、`address`、`id`、`photo`、`typecode`。详情调用以地点 ID 为参数。样本包含同一地点 ID、地点名称和坐标。分类是分号分隔的字符串，别名是字符串，营业时间字段在样本中为空。详情必须匹配原地点 ID。缺少可核验分类、别名或同一地点的坐标时返回澄清。约束会随“换一批”和城市纠错保留。 [高德 POI 2.0](https://lbs.amap.com/api/webservice/guide/api-advanced/newpoisearch)

## 充电规划

| 条目 | 当前行为 | 验收待补 |
|---|---|---|
| H02 沿途兼容站点 | 语音识别到沿途兼容充电请求时说明缺少路线、车辆接口和沿途桩兼容资料。普通附近站点仍可查询，提示空闲未知。 | 真实路线与站点关联、车辆接口、兼容数据的来源和时效。 |
| H03 到达电量目标 | 接收用户明确给出的到达保留电量百分数。缺少可信输入时明确说明，结果不含推测的里程和电量。 | 真实车辆 SOC 和采样时间、可用电量、经验证能耗与路线、兼容站点数据，之后还需要真实行程回放和目标车型实测。 |
| H04 充电与休息 | 组合补能请求进入同一个数据校验，缺少数据时不生成充电休息草稿。 | 验证停站可达性、充电和休息条件之后，才能生成可编辑草稿并沿用现有确认流程。 |

当前环境未提供可用的实车遥测和兼容桩授权数据源。普通驾车路线预览可单独提供路线估算，补能请求仍需上述可信输入。高德 Android 搜索 SDK 公开文档列出沿途充电站类别，具体产品接口能力需结合所用通道验证。 [高德沿途 POI 搜索类型](https://a.amap.com/lbs/static/unzip/Android_Map_Doc/Search/com/amap/api/services/routepoisearch/RoutePOISearch.RoutePOISearchType.html)
