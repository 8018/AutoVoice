# 导航开发版晚间验证

本版连接 dev，保留 DeepSeek Flash。服务端已部署基础找点、多站草稿、出发前路线预览和有证据的地点条件。默认手机包使用外部高德执行导航；应用内实时导航已接入实际 SDK，但需要绑定本应用的 Android 授权后才能验证。

## 安装和准备

安装包：`AutoVoice/app/build/outputs/navigation-review/AutoVoice-navigation-dev.apk`。这是包含真实讯飞运行库的 Iflytek Debug 包，不是编译替身包。保留现有应用数据安装，选择在线模式，允许录音与精确定位。手机安装高德地图后才能执行外部地图交接。

讯飞离线唤醒与命令词还需已有授权模型。用电脑安装并同步模型：

```sh
cd AutoVoice
ANDROID_HOME=/Users/michaelliu/Library/Android/sdk \
  bash tools/install-navigation-dev.sh 设备序列号 \
  app/build/outputs/navigation-review/AutoVoice-navigation-dev.apk
```

在应用首次提示时授权所需权限。没有精确、近期的位置时，路线预览会请你刷新定位，不会使用旧位置。

## 先验证这十组

| 操作 | 应看到的结果 |
| --- | --- |
| “导航到虹桥机场” | 最多三个真实候选；未选择时不打开地图。 |
| “不要去第二个”，再说“第一个” | 否定不执行，后续仅选当前列表；地图缺失时明确失败。 |
| “不是北京，是上海”“换一批” | 城市条件保留；旧列表不能再执行，新列表不循环原结果。 |
| 设置常用地址，再说“回家”“去公司” | 首次保存、覆盖或删除均按页面确认；没设置时提示设置。 |
| “先去学校，再去机场” | 每站有歧义则逐站选择，完整草稿确认后才交接；顺序不变。 |
| “去北京南站要多久，只查询路线” | 选择地点后展示真实路线时间、距离及已知费用，不启动导航。 |
| 在路线列表中换“少收费”“不走高速” | 重新请求对应偏好；外部高德出发时会自行重新规划，Web 预览不能锁定其路线 ID。 |
| “找北京现在营业的咖啡店” | 无法核验营业状态时说明未知，不把普通搜索结果冒充全部满足。 |
| “找附近充电站”“到目的地至少留两成电” | 前者可返回真实站点；后者缺 SOC、兼容数据或能耗时拒绝编造补能方案。 |
| 外部高德接管后问“还有多久”“结束导航”“导航别说话” | 不伪报外部地图状态或控制成功。实际控制请在高德内操作。 |

地图中的真实地点、途经顺序、语音效果、定位权限和设备延迟仍需你验证。完整的 208 条表达位于 [验收语料](qa/navigation-acceptance-corpus.json)，均保留为未运行，不能把自动测试替代为这些用例的通过记录。

## 应用内导航授权

本次设备包的包名为 `com.autovoice.app`，调试签名 SHA-1 为 `59:84:66:89:02:FD:F4:D9:40:BA:1D:FE:47:60:67:94:35:9F:6B:3C`。申请或配置高德 Android Key 时应绑定实际包名和签名，不能用服务端 Web Key 代替。

已有授权时，在不入库的 `AutoVoice/local.properties` 设置 `amap.androidKey`，或使用 `AUTOVOICE_AMAP_ANDROID_KEY` 环境变量后重新构建。在应用中阅读并同意高德说明后，才能启用应用内导航。请勿把 Key 提交到仓库。

应用内 SDK 已完成真实依赖编译及资源打包验证，尚未完成授权设备上的开始、进度、播报、视图和沿途搜索验证。停止请求暂只显示已受理，不能宣布地图已结束。行中增删重排和更换终点尚未开放，绕行量保持未知；自动补能还缺真实车辆及充电数据。因此本版不是全部 58 项的完整验收版本。
