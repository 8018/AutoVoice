# 任务 3 常用地址实施报告

## 接线路径

| 验收项 | 实现 |
| --- | --- |
| C01 回家 | 文字指令在云端文字提交前匹配。已采纳的语音识别文本在执行普通意图前匹配。每次重新读取本机家庭地址。未设置时引导打开「设置 → 常用地址」。 |
| C02 去公司 | 走同一入口，读取公司地址。高德仅接收本次选中的坐标和「公司地址」标签。交接反馈来自打开地图的结果。 |
| C03 设置 | 在设置中选择「使用当前位置」，或说「把这里设为家」。应用逆解析后展示具体地址，用户确认后才写入。普通导航搜索出现候选时，可使用「设为家」或「设为公司」保存同一个地点，复用既有候选坐标和任务身份。 |
| C04 修改 | 「公司换到这里了」和设置页进入同一确认流程。覆盖对话框展示当前地址和新地址。取消保留旧值。若确认期间原记录已变化，拒绝旧确认。 |
| C05 删除 | 设置页「删除」和「删除我的家庭地址」进入同一确认流程。删除持久化成功后，再次「回家」会提示重新设置。 |
| I04 地址隔离 | 当前 Android 应用使用单一本机配置，设置页说明数据保存在本机。存储按配置身份和类别隔离。现有应用没有账号切换入口。 |

- `SavedNavigationPlaceStore` 通过内部存储接口持久化。Android 适配器在应用的 `noBackupFilesDir` 下使用同目录原子替换，读取、写入或解析失败时统一返回不带地址的错误。导航每次读取持久化记录，不通过设置页的显示状态查询目的地。
- `SavedNavigationPlaces` 将确认绑定到准备时的配置和原记录，并且一次确认只能消费一次。`SavedNavigationCommandRouter` 通过现有动作网关对已采纳的语音轮次去重。手动再次发起指令生成新轮次。
- 保存「这里」使用最近 30 秒内、精度不超过 50 米的手机定位。未知、过期或过粗时请求刷新，并允许用户重试。地址由 Android 地理编码服务提供，界面只在逆解析成功时显示确认。来自 GPS 的记录保留 WGS84 标记，交给高德时使用 `dev=1`。从高德候选保存的记录保留原坐标。常规导航定位数据和网关协议沿用原结构。 [高德 Android 导航 URI 文档](https://lbs.amap.com/api/amap-mobile/guide/android/navigation/)
- 本机地址簿和实际记录名称不进入云端导航请求、普通日志或执行反馈。在线语音识别仍走原音频链路。Android 地理编码服务可能使用网络解析一次所选定位。直接使用已存地址时，应用只向高德交接本次目的地。

## 验证

在 `AutoVoice` 下执行。

```sh
./gradlew :voice-business:test :app:testOpenDebugUnitTest --offline --configure-on-demand --console=plain
./gradlew :app:assembleOpenDebug --offline --configure-on-demand --console=plain
git diff --check
```

- 业务 JVM 套件 59 项通过，Android Open Debug JVM 套件 237 项通过。地址业务测试 13 项、客户端集成测试 2 项、定位质量测试 3 项、回复分发测试 12 项均通过。
- 先添加地址测试，编译确认缺少地址存储与命令；再实现并通过。追加交接、同轮去重和定位质量测试时，分别确认缺少 `navigate`、`SavedNavigationCommandRouter`、`usableForSavedAddress` 导致红灯，实现后全量通过。
- 测试覆盖首次未设置、覆盖取消与重复确认、删除后不再交接、配置切换、过期确认、文件重开、未知和过期定位、GPS 交接标记、存储读写失败及地址诊断脱敏。回复分发测试覆盖本机地址口令覆盖同一回复里的竞争地图动作。
- Open Debug APK 打包成功。该工作区打包的 APK 仅包含 AndroidX 的原生图形库，尚未验证带实际语音原生库的安装包。

## 还需现场验收

- 真机检查定位权限、地理编码服务覆盖、确认弹窗、实际高德 URI 坐标偏移与地图开启失败。没有地理编码服务时，可使用普通导航搜索里返回的地点候选。
- 实测在线语音完整链路及其回复时序。客户端依赖已采纳的识别文本。如果实时语音通道在最终识别文本前已经开始播报，客户端只能在获得识别文本后替换后续反馈。离线识别是否能产出这些口令仍依赖当前识别通道。
